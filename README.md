💼** Portfólio Pessoal**
Bem-vindo(a) ao repositório do meu portfólio pessoal! 🌟

Este projeto foi desenvolvido com React e Tailwind CSS, e tem como principal objetivo reunir, de forma interativa e responsiva, os principais pontos da minha trajetória como desenvolvedora. Aqui você encontra informações sobre mim, meus projetos e formas de contato — tudo isso reunido em uma experiência visual que traduz minha identidade profissional.

✨ **O que este portfólio representa?******
Mais do que um simples site, este portfólio é o reflexo da minha evolução. Ele nasceu do desejo de mostrar quem sou e o que sou capaz de construir com dedicação, estudo e muita paixão por tecnologia.

Estou muito feliz com o resultado atual, mas este projeto está longe de ser um ponto final. Pelo contrário: ele é um ponto de partida. Minha intenção é continuar aprimorando cada detalhe — seja no design, na usabilidade, na acessibilidade ou na performance. A cada nova habilidade que eu adquirir, pretendo incorporar aqui.

🚧 **Em constante construção**
Sempre que aprendo algo novo, este portfólio é um dos primeiros lugares onde aplico;

Cada seção foi pensada com carinho e pode ser expandida com novos recursos no futuro;

É um projeto vivo, em evolução junto comigo.
